# BookCatalog

Каталог книг з відгуками, рейтингом і статистикою. Веб-застосунок на FastAPI з HTML-інтерфейсом та REST API (Swagger).

## Проблема, яку вирішує продукт

Читачу складно вести облік прочитаного та ділитися враженнями. BookCatalog дозволяє додати книгу, знайти її за назвою/автором, поставити оцінку, залишити відгук і побачити статистику каталогу.

**Цільовий користувач:** читач, який хоче каталогізувати книги та бачити рейтинг.

## Функціональні можливості

1. **CRUD книг** — додавання, перегляд, редагування, видалення (назва, автор, рік, жанр, опис).
2. **Пошук і фільтрація** — за назвою/автором (case-insensitive) та за жанром.
3. **Рейтинг** — оцінка 1–5, середній рейтинг книги розраховується автоматично.
4. **Відгуки** — текстовий відгук, прив'язаний до книги; каскадне видалення разом із книгою.
5. **Статистика** — кількість книг і відгуків, середній рейтинг, топ-5 жанрів.

## Технології

- **Python 3.14**
- **FastAPI** — веб + REST API
- **SQLAlchemy 2.0** + **SQLite** — ORM і зберігання
- **Pydantic v2** — валідація
- **Jinja2** — HTML-шаблони
- **pytest + httpx** — тести (14 тестів)

## Встановлення та запуск

```powershell
# 1. Клонувати репозиторій
git clone https://github.com/VSakurai/book-catalog.git
cd book-catalog

# 2. Створити venv на Python 3.14
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. Встановити залежності
pip install -r requirements.txt

# 4. Запустити
uvicorn app.main:app --reload
```

Відкрити:

- `http://127.0.0.1:8000/` — HTML-каталог
- `http://127.0.0.1:8000/stats` — статистика
- `http://127.0.0.1:8000/docs` — Swagger

## Обмеження

- Один користувач, без аутентифікації.
- SQLite — для навчального проєкту; для продакшену варто PostgreSQL.
- Немає пагінації в списку книг.

## Наступні покращення

- Пагінація та сортування списку книг.
- Аутентифікація користувачів і прив'язка відгуків до авторів.
- Експорт каталогу в CSV/JSON.
